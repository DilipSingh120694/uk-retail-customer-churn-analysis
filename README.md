# UK Online Retail Customer Churn Analysis

An MSc Business Analytics project exploring how a UK online retailer could use customer data to design a targeted retention campaign.

## What I did

- Analysed UK online retail transactions in Python and defined churn as 90 days of inactivity.
- Removed recency from the model inputs to prevent data leakage because it was already used to define churn.
- Evaluated Trustpilot reviews for additional context on customer retention.
- Recommended using purchase frequency to help identify customers for targeted retention.
